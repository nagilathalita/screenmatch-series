## 📌 Sobre o projeto

O **ScreenMatch Séries** é uma aplicação desenvolvida em Java durante meus estudos na formação Back-end Java da Alura.

O projeto tem como objetivo colocar em prática conceitos de programação funcional, expressões lambda, Streams e Spring Framework, utilizando informações de séries obtidas por meio da API OMDb.

Este repositório acompanha minha evolução no aprendizado de Java e Spring Boot, com implementações realizadas ao longo das aulas.

## 🛠️ Tecnologias utilizadas

- **Java 17** — Linguagem de programação
- **Spring Boot** — Framework para desenvolvimento da aplicação
- **Maven** — Gerenciamento de dependências
- **Jackson** — Conversão de dados JSON para objetos Java
- **OMDb API** — Consulta de informações sobre séries
- **IntelliJ IDEA** — Ambiente de desenvolvimento

## 📚 Conceitos estudados

O desenvolvimento do projeto contempla o aprendizado e a aplicação dos seguintes conceitos:

- Criação e configuração de projetos com Spring Boot
- Consumo de APIs externas
- Manipulação de dados JSON
- Modelagem de classes e objetos
- Expressões lambda
- Interfaces funcionais
- Java Streams API
- Filtragem, transformação e ordenação de coleções
- Utilização de operações como `filter()`, `map()` e `sorted()`

## 🚀 Funcionalidades

Funcionalidades trabalhadas e previstas ao longo do desenvolvimento:

- Consulta de informações de séries na OMDb API
- Conversão dos dados recebidos em objetos Java
- Organização e manipulação de informações de séries
- Aplicação de filtros e ordenações utilizando Streams
- Exploração de informações sobre temporadas e episódios

As funcionalidades serão implementadas e atualizadas progressivamente durante os estudos.

## 🔑 Configuração da API

O projeto utiliza a [OMDb API](https://www.omdbapi.com/) para consultar informações de séries.

Para realizar consultas, é necessário obter uma chave de API e configurá-la na aplicação.

**Importante:** chaves de API não devem ser publicadas diretamente no código-fonte ou no repositório.
